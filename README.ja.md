# rvemu

ドキュメント: [English](README.md) | [한국어](README.ko.md) | **日本語**

`rvemu` は、RISC-V の基本整数命令セット RV32I を実行する小規模な C インタプリタです。外部ライブラリへの依存がなく、CPU エミュレータの仕組みを理解し、機能を拡張するための出発点として設計されています。

## ビルドと実行

```sh
make
make test
./build/rvemu                 # 組み込みのサンプルを実行
./build/rvemu program.bin 100000
```

バイナリはメモリアドレス 0 にロードされ、リトルエンディアンの 32 ビット命令として解釈されます。`EBREAK` 命令で実行を終了します。実行命令数に上限を設け、ゲストプログラムの無限実行を防ぎます。現在のデフォルトメモリ容量は 1 MiB です。ELF ローダー、オペレーティングシステム、デバイスモデル、特権モードにはまだ対応していません。

## 実装済みの命令

- `LUI`, `AUIPC`: 上位即値のロードと PC 相対アドレスの計算
- `JAL`, `JALR`: ジャンプと戻りアドレスの保存
- `BEQ`, `BNE`, `BLT`, `BGE`, `BLTU`, `BGEU`: 条件分岐
- `LB`, `LH`, `LW`, `LBU`, `LHU`: メモリの読み込み
- `SB`, `SH`, `SW`: メモリへの書き込み
- 整数レジスタおよび即値を使った算術、論理、シフト、比較演算
- `FENCE`: 単一ハート環境では何もしない命令として処理
- `EBREAK`: エミュレータの実行終了に使用

未対応の命令はエラーを返します。メモリアクセスはリトルエンディアンで処理され、範囲を検査します。非アラインのデータアクセスは許可されますが、命令アドレスは 4 バイト境界にアラインする必要があります。命令が正常に実行されるたびに `x0` レジスタは 0 に維持されます。

## 設計

CPU の状態は `include/rvemu.h` で定義されています。`src/rvemu.c` はメモリ管理、命令フェッチ（fetch）、デコード（decode）、即値の符号拡張、実行（execute）、実行結果の返却を担当します。

`rvemu_step()` は命令を一つ実行し、`rvemu_run()` は指定された命令数の上限まで実行を繰り返します。この構造により、実行コアをテストや将来の別の実行環境で再利用できます。

## 今後の開発計画

1. エラー診断と命令テストの拡充
2. ELF32 ローダーの実装
3. 設定可能なメモリ領域とデバイスの実装
4. マシンモード（M-mode）の CSR とトラップの実装
5. MMU の実装
6. Linux を起動できるシステムの構築

JIT コンパイラは、インタプリタの性能を測定し、例外とメモリの動作を明確に定義した後に実装する予定です。
