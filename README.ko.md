# rvemu

문서: [English](README.md) | **한국어** | [日本語](README.ja.md)

`rvemu`는 RISC-V의 기본 정수 명령어 집합인 RV32I를 실행하는 작은 C 인터프리터입니다. 외부 라이브러리에 의존하지 않으며, CPU 에뮬레이터의 동작을 이해하고 확장하기 위한 출발점으로 설계되었습니다.

## 빌드 및 실행

```sh
make
make test
./build/rvemu                 # 내장 예제 실행
./build/rvemu program.bin 100000
```

바이너리는 메모리 주소 0에 적재되며 리틀 엔디언 32비트 명령어로 해석됩니다. `EBREAK` 명령어를 만나면 실행을 종료합니다. 명령어 실행 횟수에 제한을 두어 게스트 프로그램의 무한 실행을 방지합니다. 현재 기본 메모리 크기는 1 MiB이며 ELF 로더, 운영체제, 장치 모델, 특권 모드는 아직 지원하지 않습니다.

## 구현된 명령어

- `LUI`, `AUIPC`: 상위 즉시값 적재 및 PC 상대 주소 계산
- `JAL`, `JALR`: 점프 및 복귀 주소 저장
- `BEQ`, `BNE`, `BLT`, `BGE`, `BLTU`, `BGEU`: 조건 분기
- `LB`, `LH`, `LW`, `LBU`, `LHU`: 메모리 읽기
- `SB`, `SH`, `SW`: 메모리 쓰기
- 정수 레지스터 연산 및 즉시값을 사용하는 산술·논리·시프트·비교 연산
- `FENCE`: 단일 하트 환경에서 아무 동작도 하지 않는 명령어로 처리
- `EBREAK`: 에뮬레이터의 실행 종료에 사용

지원하지 않는 명령어는 오류를 반환합니다. 모든 메모리 접근은 리틀 엔디언 방식이며 범위를 검사합니다. 비정렬 데이터 접근은 허용하지만 명령어 주소는 4바이트 정렬이 필요합니다. 각 명령어의 정상 실행 후 `x0` 레지스터를 항상 0으로 유지합니다.

## 설계

CPU 상태는 `include/rvemu.h`에서 정의합니다. `src/rvemu.c`는 메모리 관리, 명령어 인출(fetch), 해독(decode), 즉시값의 부호 확장, 실행(execute) 및 상태 반환을 담당합니다.

`rvemu_step()`은 명령어 하나를 실행하고, `rvemu_run()`은 정해진 실행 횟수까지 반복합니다. 이 구조는 실행 코어를 테스트나 향후 다른 실행 환경에서 재사용할 수 있도록 합니다.

## 향후 개발 계획

1. 오류 진단 및 명령어 테스트 확대
2. ELF32 로더 구현
3. 설정 가능한 메모리 영역 및 장치 구현
4. 머신 모드(M-mode)의 CSR 및 트랩 구현
5. MMU 구현
6. Linux 부팅이 가능한 시스템 구성

JIT 컴파일러는 인터프리터의 성능을 측정하고 예외 및 메모리 동작을 명확하게 정의한 후 구현할 계획입니다.
